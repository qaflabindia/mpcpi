MPCPI

Multipolar Currency Pricing & Invoicing — BCC-T / BCC-C / BCC-D workbench

Installed. Press Alt+Shift+M on any page, or click the toolbar icon, to open the floating panel. You can start with the built-in sample dataset — no key or configuration needed for the arithmetic. A model provider is only required for the Agent tab.

How it works

  1. Load a Google Sheet, an Excel workbook or a CSV. Column headers are matched fuzzily and every uncertain match is reported.
  2. A triangularly consistent cross-rate matrix is fitted from your quotes by weighted least squares (§8).
  3. BCC-T is constituted as a fixed quantity vector with a concentration cap (§6).
  4. Leading and lagging indicators are scored against fixed reference distributions, never cross-sectional min-max (§11).
  5. Obligations are netted multilaterally and tested for creditor persistence (§19, §20).
  6. Each invoice is priced as a transparent sum of named components, with the dollar-intermediated route priced beside it.

Model provider

Optional. The whole computation runs without one; a provider is needed only for the Agent tab. Keys live in this browser profile's extension storage and are sent only to the provider you pick.

Running a local model

Ollama refuses cross-origin requests by default, so it has to be told that an extension may call it:

OLLAMA_ORIGINS="chrome-extension://*" ollama serve

On macOS, if Ollama runs as a background app: launchctl setenv OLLAMA_ORIGINS "chrome-extension://*", then restart it.

LM Studio, vLLM, LocalAI, Groq, Together and OpenRouter all work through the OpenAI-compatible endpoint provider — set the base URL and, where needed, a key.

MCP servers

Add them from the panel's Settings tab. HTTP and SSE transports work; a stdio server needs an HTTP bridge, because an extension cannot spawn processes. Tool calls to an MCP server leave your machine, so each one asks for approval until you allow that server.

Privacy

  • Spreadsheets are parsed in the panel. Their contents are never uploaded.
  • Results live in a local SQLite database in this browser profile, exportable as a file.
  • Google Sheets are fetched with your existing browser session, so private sheets work without any token being stored.
  • No telemetry, no analytics, no remote logging. The only outbound calls are to the model provider you select and to MCP servers you add.
  • API keys are never written to the database, the trace log or an export.

What this is not

This implements a research proposal. The framework's own text identifies its central questions as untested — whether real BRICS flows net efficiently above all (§20, §34). Prices produced here are illustrative decompositions computed from the data you supply, not quotes, not advice, and not a claim that the direct route is cheaper. Where your data says the dollar route costs less, the tool says so.
