Model provider

Keys are held in this browser profile's extension storage and are sent only to the provider you select. They are never written to the SQLite database, never logged and never sent anywhere else.

MCP servers

Connects to HTTP or SSE MCP servers. A stdio server needs an HTTP bridge in front of it — a browser extension cannot spawn processes. Tools from these servers leave your machine, so each call asks for approval unless you allow the server.

Scoring yardsticks §11

The yardsticks each indicator is scored against. Set them once from a reference period and then leave them alone — that is what lets you compare a score from this year against one from ten years hence. Rescaling them against whoever happens to be in the data today would mean one country having a bad year silently moved everybody else's score.

About

MPCPI 1.0.0 — an implementation of the BCC-T / BCC-C / BCC-D framework.

This is a research instrument. The framework it implements is an untested institutional proposal, and several of its central claims — netting efficiency on real BRICS flows above all — are explicitly identified as open empirical questions (§20, §34). Prices produced here are illustrative decompositions, not quotes, and nothing here is investment advice.

No telemetry. No analytics. Nothing leaves this browser except calls to the model provider you choose and the MCP servers you connect.
